작성자가 소개한 방향은 6돌파 도술 없이 맞추는 무소과금·소과금 광역 덱입니다.

생존 도술을 먼저 사용하고, 파멸 즉발기와 강타 차지기를 이어서 평타 구간을 줄이는 구성입니다.

1｜앤단덱 핵심 세팅

도술은 검기 날리기, 검기 폭발, 하늘의 심판, 요기 폭발, 번개 폭풍, 대검 강타, 방패 밀기, 생명의 흐름을 사용합니다.

궁극기는 파멸 계열 대폭발입니다.

생명의 흐름과 방패 밀기로 회복·보호막을 챙깁니다.

그다음 대폭발과 파멸 도술로 광역 피해를 넣고, 강타 차지기로 앞 도술의 재사용 대기시간을 돌립니다.

2｜작성자 도술 순서

생명의 흐름 → 방패 밀기 → 대폭발 → 요기 폭발 → 하늘의 심판 → 번개 폭풍 → 검기 폭발 → 검기 날리기 → 대검 강타

이 순서는 앤단이 등록한 기본 사용 순서입니다.

작성자는 평균 재사용 대기시간이 11초 이상인 도술을 기준으로 순환을 설명합니다.

회복과 보호막을 먼저 사용하고, 즉시 발동하는 파멸 도술 뒤에 차지 시간이 있는 강타 도술을 배치합니다.

3｜무힐 대체 순서

생존이 충분하다면 작성자는 생명의 흐름과 방패 밀기를 빼는 무힐 구성도 안내합니다.

대폭발 → 요기 폭발 → 돌풍 강격 → 하늘의 심판 → 번개 폭풍 → 크게 베기 → 검기 폭발 → 검기 날리기 → 대검 강타

하늘의 심판과 요기 폭발이 6돌파라면 연쇄 번개를 넣는 대안도 있습니다.

재사용 대기시간이 달라지면 평타 구간이 생길 수 있으므로 보유 도술과 돌파 상태를 먼저 확인해야 합니다.

파멸 피해를 보완할 전설 무기로 파멸 지팡이가 괜찮아 보인다는 내용도 작성자의 의견입니다.

4｜계산기 추천 순서

깨비지지 추천 순서는 대폭발 → 방패 밀기 → 하늘의 심판 → 번개 폭풍 → 요기 폭발 → 검기 날리기 → 대검 강타 → 검기 폭발 → 생명의 흐름입니다.

작성자 등록 순서와 계산기 추천 순서는 서로 다릅니다.

처음 적용할 때는 작성자 등록 순서를 기준으로 맞추고, 계산기 순서는 비교 정보로 보면 됩니다.

깨비지지 1분 계산값은 작성자 순서 DPS 231%, 추천 순서 243%입니다.

회복 계수는 300%, 실드 계수는 350%입니다.

모두 사이트가 공개한 계산값이며 미바가 직접 측정한 결과는 아닙니다.

5｜사용 전 확인할 점

현재 깨비지지 유형 배지는 `단일`로 표시됩니다.

반면 덱 제목과 작성자 본문은 10인 범위 `광역` 덱으로 설명합니다.

분류가 바뀐 이유는 공개되지 않았으므로 두 정보를 같은 의미로 단정하면 안 됩니다.

작성자가 공개한 무한 순환, 상위 사냥터 가능, 분당 약 60~80마리도 미바가 재현한 결과가 아닙니다.

정확한 게임 패치 번호는 확인되지 않았고, 추천수와 순위는 계속 바뀔 수 있습니다.
