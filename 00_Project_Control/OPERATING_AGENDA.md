# 운영 아젠다

## 작업 흐름

1. Master가 게임, 주제, 기준 날짜와 담당 세션을 정하고 자동 큐에 등록한다.
2. 입력이 준비된 작업은 별도 착수 요청을 기다리지 않고 담당 세션이 즉시 시작한다.
3. 자료조사 세션이 출처를 확인하고 조사 MD를 작성한다.
4. 자료조사 세션이 `04_Handoffs/`에 차원의문 전달 문서를 작성한다.
5. 조사·전달 문서가 검수를 통과하면 차원의문 작업을 자동으로 해제하고 즉시 시작한다.
6. 차원의문이 조사 문서, 전달 문서, 스타일 가이드와 제공된 미디어를 읽는다.
7. 차원의문이 `05_Posts/`에 백업 원고를 작성한다.
8. 연결된 네이버 블로그 편집기에 원고와 미디어 배치안을 반영하고 임시저장한다.
9. 공개 발행은 사용자가 명시적으로 요청한 경우에만 수행한다.
10. Master가 누락, 출처, 미확인 정보, 블로그 임시저장 상태와 Git 상태를 검수한다.

## 자료조사 완료 기준

- 출처 URL과 확인 시각이 있다.
- 순위와 추천수 등 변동값에 기준 시각이 있다.
- 스킬·아이템·옵션의 고유명사가 확인됐다.
- 사실과 작성자 의견이 구분됐다.
- 차원의문이 추가 질문 없이 글의 구조를 잡을 수 있다.
- 확인하지 못한 항목이 별도로 표시됐다.

## 글 작성 완료 기준

- 미바 스타일 가이드를 적용했다.
- 제목에서 게임과 빌드가 바로 보인다.
- 세팅 → 운용 → 주의사항 순서가 분명하다.
- 이미지와 GIF 위치가 관련 설명 가까이에 제안됐다.
- 사냥 결과를 기본 항목으로 요구하지 않는다.
- 조사 문서에 없는 경험과 수치를 만들지 않았다.
- 연결 블로그 작성 요청이면 네이버 편집기에 입력하고 임시저장했다.
- MD 백업만 생성한 상태를 게시글 작성 완료로 판정하지 않았다.

## 주간 점검

- 오래된 조사 자료의 최신성
- `BLOCKED` 작업과 필요한 사용자 입력
- 같은 주제의 중복 조사
- 완성 원고에 연결되지 않은 조사 문서
- 커밋되지 않았거나 푸시되지 않은 변경
