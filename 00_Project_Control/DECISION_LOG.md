# 의사결정 기록

## 2026-11-06

- 도깨비의세계 자료조사는 아구몬 세션이 담당한다.
- 아구몬은 깨비지지를 기본 출처로 사용한다.
- 디아블로4 자료조사는 파피몬 세션이 담당한다.
- 파피몬은 `https://tools.infinitybuilds.gg/ko`를 1순위 출처로 사용한다.
- 디아블로4 인벤은 파피몬의 2순위 출처로 사용한다.
- 네이버 블로그 원고는 차원의문 세션이 담당한다.
- 차원의문은 다른 세션의 조사 결과를 우선 입력으로 사용한다.
- 사냥 결과와 반복 측정값은 기본 원고 구성에서 제외한다.
- GitHub MD를 세션 간 공용 작업 기억으로 사용한다.
- 저장소의 작업 배정은 다른 채팅 세션을 자동 실행하지 않는다. 대상 세션의 직접 착수 또는 별도 오케스트레이터 호출이 필요하다.
- 작업 배정만 완료된 상태는 `TODO`로 유지하고, 실제 착수 증거를 확인한 뒤 `IN_PROGRESS`로 변경한다.
- 활성 Master는 새 작업과 의존성이 해제된 후속 작업을 별도 착수 지시 없이 즉시 역할 에이전트에 배정한다.
- Master 비활성 시간의 상시 실행은 자동 큐와 GitHub Actions 디스패처를 사용한다. AI 실행 자격증명이 없으면 큐 검사만 수행한다.
- Master는 수동 작업표 관리자가 아니라 하위 역할 에이전트를 생성·재개하고 완료 후속 작업을 연쇄 실행하는 상위 오케스트레이터 에이전트다.
- 사용자가 공개 출처 조사에 필요한 사용 가능한 접근 경로 사용을 승인했다. 환경 정책이나 사이트 접근 통제를 우회하지 않으며, 제공된 도구 범위에서 직접 접속·연결 브라우저·공개 색인·공식 연결 출처를 모두 시도한다.
- 연결 블로그 작성 요청의 완료 기준은 네이버 블로그 편집기 입력과 임시저장 확인이다. `05_Posts/`의 MD는 백업 원고이며 MD 생성만으로 완료 처리하지 않는다.
- 네이버 블로그 공개 발행은 사용자가 명시적으로 요청한 경우에만 수행한다.

새로운 운영 결정을 확정하면 날짜, 결정 내용, 영향받는 세션을 추가한다.
