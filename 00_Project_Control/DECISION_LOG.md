# 의사결정 기록

## 2026-11-06

- 도깨비의세계 자료조사는 아구몬 세션이 담당한다.
- 아구몬은 깨비지지를 기본 출처로 사용한다.
- 디아블로4 자료조사는 파피몬 세션이 담당한다.
- 파피몬은 `https://tools.infinitybuilds.gg/ko`를 1순위 출처로 사용한다.
- 디아블로4 인벤은 파피몬의 2순위 출처로 사용한다.
- 네이버 블로그 원고는 차원의문 세션이 담당한다.
- 차원의문은 다른 세션의 조사 결과를 우선 입력으로 사용한다.
- 사냥 결과와 반복 측정값은 기본 원고 구성에서 제외한다.
- GitHub MD를 세션 간 공용 작업 기억으로 사용한다.
- 저장소의 작업 배정은 다른 채팅 세션을 자동 실행하지 않는다. 대상 세션의 직접 착수 또는 별도 오케스트레이터 호출이 필요하다.
- 작업 배정만 완료된 상태는 `TODO`로 유지하고, 실제 착수 증거를 확인한 뒤 `IN_PROGRESS`로 변경한다.

새로운 운영 결정을 확정하면 날짜, 결정 내용, 영향받는 세션을 추가한다.
