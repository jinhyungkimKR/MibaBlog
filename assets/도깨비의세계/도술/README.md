# 도깨비의세계 도술 신식 자료

블로그 작성에 사용하는 도술 신식 설명 이미지와 스킬 GIF를 보관합니다.

## 폴더 구조

```text
신식/
├── images/       신식 영력 설명 스크린샷
└── gifs/         계열별 스킬 GIF
    ├── 강인/
    ├── 강타/
    ├── 기동/
    ├── 기만/
    ├── 연타/
    ├── 저격/
    ├── 절명/
    ├── 주술/
    ├── 파멸/
    └── 헌신/
```

## GIF 편집 기준

- 영상에서 마우스 포인터가 보이지 않는 두 번째 시연만 사용
- 동작 직전부터 이펙트가 끝나는 부분까지 편집
- 가로 700px, 10fps, 무한 반복
- 파일명은 `순번_스킬명.gif` 형식 사용
