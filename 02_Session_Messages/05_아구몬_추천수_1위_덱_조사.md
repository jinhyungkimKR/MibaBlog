# 아구몬 신규 작업 지시

## 작업

깨비지지 덱 목록에서 추천수 기준 1위인 도깨비의세계 덱을 조사한다.

## 출처

- 덱 목록: `https://kkaebigg.com/deck/`
- 추천수 기준 1위 덱의 개별 상세 페이지

현재 화면의 노출 순서만 보고 1위로 판단하지 않는다. 추천수 정렬을 실제로 적용하고, Asia/Seoul 기준 확인 시각과 당시 추천수를 함께 기록한다. 동률이면 동률 덱을 모두 기록하고 임의로 한 개를 선택하지 않는다.

## 필수 수집 항목

- 덱 목록과 개별 덱의 정확한 URL
- 확인 시각, 정렬 기준, 순위와 추천수
- 덱 이름과 공개된 작성자 정보
- 도술 구성과 배치 순서
- 스킬별 정확한 이름과 페이지 설명
- 예상 DPS, 추천 우선순위 적용 수치 등 페이지의 공개 수치
- 기존 `assets/도깨비의세계/`에서 연결 가능한 이미지·GIF 경로
- 확인된 사실, 출처 작성자의 의견, 세션의 해석 구분
- 확인할 수 없거나 추가 검증이 필요한 항목

접근이 막히거나 추천수 정렬을 확인할 수 없으면 추측하지 말고 `BLOCKED`와 필요한 사용자 입력을 기록한다.
