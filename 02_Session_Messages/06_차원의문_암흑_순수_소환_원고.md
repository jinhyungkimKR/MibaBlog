## 작업

## 작성 조건

- 제목에서 디아블로4와 암흑 순수 소환 빌드를 바로 식별할 수 있게 한다.
- 세팅 → 스킬 → 운용 → 개척·파밍·고단 변형 → 주의사항 순서로 구성한다.
- 구덩이 150단·2분 30초 기록은 원문 작성자가 공개한 결과로 표현한다.
- 조사 문서에 없는 직접 플레이 경험, 성능 수치와 시즌 정보를 만들지 않는다.
- 10월 24일 업데이트의 적용 연도와 시즌·패치가 확인되지 않았다면 확정 표현을 사용하지 않는다.
- 누락된 정보는 파피몬 재조사 요청 항목으로 분리한다.
- 관련 이미지·GIF가 전달되지 않았다면 임의의 미디어 경로를 만들지 않는다.
